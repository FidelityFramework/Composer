# Single-board computer targets

KeyStation targets Libre Computer **AML-S905X-CC-V2 (Sweet Potato)**, using the
Amlogic S905X, Cortex-A53 CPU cores and Mali-450 GPU. Board identity and source
evidence belong to the
[Fidelity.Platform product entry](../../../Fidelity.Platform/Hardware/Products/LibreComputer/AML_S905X_CC_V2/README.md).

The [native port plan](../../../Fidelity.Platform/docs/SWEET_POTATO_UI_PORT.md)
defines the Clef unikernel path and its Linux reference. Boot and GPIO samples
must use the S905X board wiring and an accepted AArch64 firmware handoff. This
directory currently has no executable SBC sample.
